# DR Officiant Website

This is the Jekyll source for the DR Officiant website.

Most future content should be added as Markdown files inside `guides/` and `locations/`.
The shared design lives in `_layouts/`, `_includes/`, and `assets/css/`.
The homepage is `index.md`.

Enable GitHub Pages in Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

The site currently contains placeholders rather than finished business copy. Replace those with your own writing before launch.
Verify legal and organizational information against current official sources before publishing definitive guidance.
